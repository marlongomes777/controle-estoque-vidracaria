# Sistema de Controle de Estoque para Vidraçaria

## Descrição

Projeto acadêmico desenvolvido para a disciplina de Banco de Dados.

## Objetivo

Desenvolver um banco de dados para controlar fornecedores, clientes, materiais, estoque e movimentações de uma vidraçaria.

## Funcionalidades

- Cadastro de fornecedores
- Cadastro de clientes
- Cadastro de materiais
- Controle de estoque
- Registro de pedidos
- Registro de movimentações
- Consultas SQL
